# Test data for the plan importer

Real plans and calendar from the 2026-27 course at Institut Jaume Huguet (Valls), converted to the importer format described in `PLAN.md` section 4. Generated by `tools/build_test_data.py` from the `~/CFGS` repository; the generated files are committed so tests never need that repository.

```
holidays-centre-2026-27.txt   shared school calendar in the holiday-line format
plans/0372.md                 MP 0372 · 60 days · Mon + Fri, 2 h
plans/0374.md                 MP 0374 · 61 days · Mon + Thu, 2 h
plans/0377.md                 MP 0377 · 27 days · Tue, 1 h
cases/*.md                    hand-made edge cases, one issue type each
cases/expected.json           the errors and warnings each case must produce
expected.json                 module, blocks, days, hours, dates and issues each real plan must produce
```

School year: 2026-09-14 to 2027-06-21, evaluations 14/9 to 27/11, 30/11 to 26/2 and 1/3 to 21/6 (see `expected.json`).

## Check everything

```bash
python3 tools/check_plan.py --selftest
```

It parses every plan and case with the reference parser and compares the result with the expected files (14 checks). The PHP importer must reproduce the same results: load the same files from PHPUnit data providers.

## Check one plan

```bash
python3 tools/check_plan.py test-data/plans/0372.md \
  --holidays test-data/holidays-centre-2026-27.txt --timetable 0:2,4:2 --year 2026-09-14:2027-06-21
```

`--timetable` is `weekday:hours` with Monday = 0.

## Regenerate

```bash
python3 tools/build_test_data.py            # reads ~/CFGS; needs python-docx and PyYAML
python3 tools/check_plan.py --selftest
```

Regenerating changes the real plans when the guides change. If the self test then fails, the importer's expectations in `expected.json` have to be reviewed, not just overwritten.
